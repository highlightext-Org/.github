Concept

Highlightext is a text-highlighting project intended to make important information easier to spot during research, analysis, and everyday work. Its brand combines black and electric yellow with the familiar visual metaphor of a highlighter.

The brand artwork states: “Spot key information instantly,” “Built for research & analysis,” “Privacy first, works locally,” and “AI-assisted highlights (optional).” These are brand concepts, not verified capabilities of a released product.

Current implementation and project status

The visual website includes a working browser-local keyword demonstration. Readers can choose Research, Contracts, or Campaigns, enter comma-separated terms, apply case-insensitive literal matches, and hide or show highlights. Example passages are illustrative. The demo makes no network requests and does not implement AI.

This repository contains project descriptions, brand artwork, a target-market research file, keyword settings, profile exports, and a master-data builder. It does not currently include a released extension, an installation package, or an AI highlighting service.

This alternative page is plain semantic HTML: no JavaScript, CSS, images, tracking, external fonts, or rendering dependencies. All information is available directly in the source.

Proposed use cases

  • Financial research: disclosures, financial terms, and risk factors.
  • Legal and compliance review: clauses, exclusions, regulatory references, and renewal dates.
  • Marketing and communications: brand names, competitors, campaign requirements, and media mentions.
  • Recruiting and project operations: role requirements, deliverables, dependencies, and deadlines.
  • Academic research: technical terms, citations, and relevant findings.

These examples come from the supplied target-market research. They describe intended applications, not customer adoption. Occupational counts are not presented as paying-user or market-size claims.

Data and configuration

The keyword settings export supports named profiles and keywords with text, color, type, and enabled state. The master-data script normalizes explicit X handles and profile identities, preserves source observations and conflicting values, and keeps holdings and keyword settings as distinct record types.

Run the local data builder from the words directory:

python3 scripts/build_master.py

Its default output is words/master.json. This website does not load or expose the profile, wallet, or contact datasets.

01 / FEATURE AREA

Keyword discovery & highlighting

Find the words that matter.

Use literal keywords and JavaScript regular expressions, named groups, category colors, case controls, and whole-word matching. Highlight visible posts, comments, biographies, and timelines as you browse.

  • Import and export keyword and regex definitions as CSV or JSON.
  • Keep separate groups and rules for each project; enable or disable individual rules.
  • Add spelling variations, synonyms, and slang as explicit rules. Cache definitions for use between sessions.

Planned: Wildcard shortcuts, dedicated exclusions, per-website issue counters, and automatic sentiment tagging are planned. Regex patterns can express alternatives today.

02 / FEATURE AREA

Public profile discovery

Keep useful identities in context.

Current tools match configured handles and profile URLs, and let you save profile links to project queues for review.

  • Open saved profiles directly and avoid duplicate queue entries.
  • Keep matching page text, source URLs, rule details, and capture timestamps in optional local match records.

Planned: Broader profile collection is planned: publicly visible names, handles, bios, links, follower/following counts, account age, verification, pinned posts, matched-content counts, last-seen history, and deduplication across collections. Availability will depend on what the page exposes.

03 / FEATURE AREA

Profile filters

Narrow the review list.

The roadmap includes profile filters to help researchers organize public information before reviewing individual records.

Planned: Planned filters include minimum and maximum follower/following counts, their ratio, account age, public verification, country, state, city, region, USA-only and VIP-only views, plus exclusions for reviewed, followed, blocked, or ignored profiles. Location labels will distinguish verified, self-declared, uncertain, and unknown; a storefront, device region, or language alone does not establish residency.

04 / FEATURE AREA

Following & engagement review

Keep a person in the loop.

Save handles and public profile URLs to a project queue, open profiles for inspection, and mark manual reviews or skip entries. Facebook, Instagram, and TikTok queues currently use manual review.

  • Queue entries persist locally and duplicate entries are skipped.
  • The X queue includes a user-started runner with follow outcomes and stop controls; it is separate from keyword matching.

Planned: Keyword-triggered review queues, priority lists, a full manual follow history, dedicated exclusions, and capture of public questions with responses approved before publishing are planned. This roadmap uses human review for political-comment matches rather than automatic following based on those comments.

05 / FEATURE AREA

Timeline & comment capture

Save the source with the signal.

Record visible timeline posts on X, Instagram, and TikTok while browsing. Save text, author and publication time when available, permalink, timeline URL, and capture time.

  • Start or stop recording independently of keyword matching; export records as CSV or JSON.
  • Deduplicate repeated posts per project and keep saved progress across browser sessions.
  • Optionally record keyword matches with their category, source, timestamp, and project.

Planned: Dedicated reply and full-thread capture, engagement counts, structured hashtags and mentions, timeline imports, version comparisons, and an in-tool manual screenshot action are planned. Current capture depends on rendered content and does not fetch hidden material.

06 / FEATURE AREA

Community sentiment & issues

Turn observations into questions.

The roadmap brings issue organization and review tools to collected public discussions.

Planned: Planned tools include positive, negative, neutral, and uncertain sentiment labels; recurring complaint and topic detection; similar-question groups; match frequency; cross-platform and over-time comparisons; and issue reports with sources and timestamps. Uncertain classifications will be flagged for review. Collected comments are observations of public content, not representative measurements of voter opinion.

07 / FEATURE AREA

VIP user highlighting

Recognize relevant public voices.

Configured handles and profile URLs can already serve as matching rules. A dedicated VIP workflow is planned for selected, publicly identified stakeholders.

Planned: Planned VIP tools include labels and category colors, username highlights, notes, list import/export, cross-platform identity review, and an activity feed. Categories may include public officials, journalists, community organizations, local businesses, and public subject-matter experts.

08 / FEATURE AREA

Storage, import & export

Keep your work close.

Keep project rules, overrides, group choices, and optional records in browser-local storage. Import and export definitions and export keyword-match and timeline records as CSV or JSON.

  • Sync central definitions on demand, with optional daily checks and an offline cache.
  • Separate research projects and retain saved rules and recording state between sessions.
  • Clear a project’s records separately from its page highlights. Export regularly: current storage has retention limits.

Planned: A full searchable profile database, timeline-data imports and merges, processed/unprocessed collection states, complete profile exports, and dedicated VIP list exports are planned.

09 / FEATURE AREA

Controls & workspace

Work beside the page.

Use the popup, Chrome/Edge side panel, or Firefox sidebar. Switch projects, manage rules, toggle automatic highlighting, and start, stop, clear, or download timeline recordings.

  • See the last successful sync, download errors, and invalid-rule diagnostics.
  • Keep recording active while browsing, including with the popup or sidebar closed.
  • Matching uses a separate worker with deadlines and page limits.

Planned: A unified collection dashboard with pause/resume/reset controls, configurable collection limits, per-platform switches, discovery/match/duplicate counters, searchable captured records, activity and error logs, and per-website permission controls is planned.
